===========================

admin.js

OPTIONAL LEGAL FILES
--------------------
privacy.html
terms.html
affiliate-disclosure.html

HOW TO USE
----------
1. Keep all files in the same folder.
2. Keep Logo.png and upi-qr.png in the same folder.
3. Open index.html to test the website.
4. Open admin.html to add products.
5. Products saved by admin.html appear on index.html in the same browser/device.

IMPORTANT
---------
This version uses browser LocalStorage for the product catalogue and demo customer account.
It is NOT a production database and is NOT secure enough for real customer authentication,
real payments, or a public multi-user marketplace.

Affiliate links must come from authorized affiliate programs. The platform buttons currently
include direct official website URLs. Replace "#" in script.js with your authorized affiliate
URL only when you have an approved affiliate link or official API integration.

The social links supplied by the owner are already included for Instagram, Pinterest, Facebook,
WhatsApp Channel and YouTube. X/Twitter and Telegram are placeholders until official links are supplied.

For production launch, add a real backend/database, secure authentication, server-side admin
authorization, payment gateway, moderation, privacy/legal pages, HTTPS, analytics and SEO.
